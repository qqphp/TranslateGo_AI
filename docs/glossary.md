# 术语表

| 术语 | 定义 |
|---|---|
| 整页翻译 | 对当前网页主文档中符合范围的可见文本节点进行批量翻译并回写页面。 |
| 选中文本翻译 | 用户在网页中选中一段文字后，调用翻译服务并在插件 UI 中展示结果。 |
| OpenAI 兼容 API | 使用与 OpenAI Chat Completions 类似请求/响应结构的 HTTP API；具体兼容程度由端点决定。 |
| Base URL | 用户配置的 API 服务根地址，插件在其上拼接请求路径。 |
| 可见文本节点 | 位于当前主文档、面向用户展示且不属于排除元素的 DOM 文本节点。 |
| 替换模式 | 用译文临时覆盖原文显示，同时保留恢复原文所需的映射。 |
| 保留原文模式 | 原文继续显示，并在其附近插入或关联显示译文。 |
| 原始文本 | 翻译任务开始前从网页节点提取的文本；是重试、切换语言和避免重复翻译的基准。 |
| 分段翻译 | 将网页文本按上下文、长度和 API 限制拆成多个请求单元，再合并结果。 |
| 翻译批次 | 一次整页翻译操作产生的一组分段请求及其页面回写结果。 |
| 主文档 | 当前标签页的顶层 document；第一版不包含 iframe 文档。 |
| 配置档案 | 一组可命名、保存和切换的 API 与翻译参数。 |
| 当前档案 | 当前翻译任务默认使用的配置档案。 |
| 批量节点翻译 | 将多个 DOM 文本节点连同稳定节点 ID 一次发送，并按返回 ID 将译文回写到对应节点。 |
| 译文元素 | 插件插入页面的、承载翻译结果并带有插件标识的 DOM 元素。 |
| 翻译批次状态 | 一次整页翻译从开始到结束的状态，包括运行中、已完成、部分失败、已取消和失败。 |
| 选中文字右键入口 | 用户选中文本后，通过浏览器右键菜单中的“翻译选中文字”显式触发翻译。 |
| 翻译气泡 | 选中文本翻译结果的临时浮层，显示在选区附近。 |
| 受限页面 | Chrome 不允许普通扩展注入或访问的页面，例如 `chrome://` 页面和 Chrome Web Store。 |
| Service Worker | Manifest V3 扩展的后台事件上下文，负责配置读取、API 请求、普通 JSON 响应解析和任务协调。 |
| Content Script | 注入网页主文档、负责 DOM 读取/回写和页面内交互 UI 的扩展脚本。 |
| 任务 ID | 标识一次翻译操作，用于关联消息、进度、取消和错误。 |
| 节点 ID | 标识整页翻译中一个待翻译文本节点，用于把响应回写到正确位置。 |
| 固定低并发 | 使用预设的少量并发请求处理节点；第一版默认并发数为 3。 |
| 固定翻译提示词 | 插件内置、用户不可编辑的系统提示词，用于统一语言方向和纯译文输出契约。 |
| MVP 发布门槛 | 第一版必须通过的完整核心链路和质量条件，而不是单个 API 调用成功。 |
| 真实网页测试集 | 用于发布验收的一组新闻、文档、论坛、SPA 和表单密集网页样本。 |
| Base URL 校验 | 对用户配置的 API 地址执行协议和格式检查；第一版要求 HTTPS，localhost 可例外。 |
