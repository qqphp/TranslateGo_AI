# ADR-0036：单节点整页翻译使用纯文本响应

- 状态：已接受
- 日期：2026-07-28

## 背景

整页翻译已配置为每个文本节点单独发起请求，但请求仍沿用多节点批量翻译的 JSON 数组协议。模型需要理解并生成节点 ID、字段名和 JSON 标点，格式错误还会触发重试，增加了不必要的提示词、输出 token 和等待时间。

## 决策

当请求只包含一个节点时，使用与选中文本翻译相同的纯文本响应协议：请求只包含精简的翻译指令、源语言、目标语言和原文，响应只允许译文。节点 ID 留在本地调度器中，不发送给模型。

固定系统提示词精简为：`Translate the text. Return only the translation, without quotes, labels, notes, or Markdown.`

只有未来单次请求包含多个节点时，才使用带节点 ID 的 JSON 数组协议。

## 影响

- 每节点请求和响应都更短，模型可以更早开始生成有效译文。
- 消除单节点 JSON 序列化、解析以及格式不合法导致的重试。
- 继续保持一个节点一个请求、最多并发 5 个、按页面顺序回写以及非流式响应。
