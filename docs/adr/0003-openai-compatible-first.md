# ADR-0003：第一版以 OpenAI 兼容 API 作为唯一接入协议

- 状态：已接受
- 日期：2026-07-26

## 背景

“支持绝大部分主流大模型”如果按原生供应商逐个实现，会带来持续的协议适配、认证和回归成本。大量中转站、自部署服务和模型网关已经提供 OpenAI 兼容接口。

## 决策

第一版只实现 OpenAI 兼容 API：用户配置 Base URL、API Key、模型名。暂不内置 OpenAI、Anthropic、Google 等原生协议适配器。

## 影响

- 供应商适配器数量降为一个协议实现。
- “支持某模型”由用户配置的兼容端点决定，而不是插件内置模型清单决定。
- 原生协议适配可以在未来以独立 Provider Adapter 扩展，但不属于当前 MVP。
