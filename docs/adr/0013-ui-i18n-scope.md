# ADR-0013：UI 国际化语言范围与目标语言一致

- 状态：已接受
- 日期：2026-07-26
- 更新：2026-07-28

## 决策

界面语言支持目标语言列表中的全部 17 种语言：简体中文、繁体中文、英文、日文、韩文、法文、德文、西班牙文、葡萄牙文、俄文、阿拉伯文、意大利文、泰文、越南文、印尼文、印地文和土耳其文。默认跟随浏览器语言；浏览器语言未被支持时回退到英文。

界面语言选择器使用本地语言名称展示各选项；主标题按当前界面语言翻译，副标题固定显示英文 `language`。阿拉伯文界面使用从右到左布局。

网页翻译的源语言和目标语言不受界面语言自动推断影响，仍由用户手动选择。
