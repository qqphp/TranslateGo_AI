# ADR-0002：采用纯本地直连的大模型调用架构

- 状态：已接受
- 日期：2026-07-26

## 背景

产品需要调用大模型 API，但当前不建设后端服务。后端代理会引入服务器成本、账号体系、计费、隐私和运维问题。

## 决策

插件在本地保存用户配置，并直接调用用户选择的 OpenAI 兼容 API。用户自行提供 Base URL、API Key 和模型名。第一版不建设产品后端、不代管用户密钥。

## 约束与风险

- API Key 必须使用 Chrome Extension Storage 的合适存储机制，并明确本地安全边界。
- 需要处理供应商 CORS、网络失败、超时、限流和错误信息脱敏。
- 插件权限必须最小化，不能默认收集网页内容或翻译结果。
- 后续如增加代理模式，需另立 ADR，不得默认为现有架构隐式引入后端。
