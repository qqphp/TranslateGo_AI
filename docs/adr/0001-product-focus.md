# ADR-0001：产品首要场景聚焦整页网页翻译

- 状态：已接受
- 日期：2026-07-26

## 背景

产品同时包含整页翻译、选中文本翻译、多模型接入、国际化等目标。若没有首要成功标准，第一版会在功能广度与网页翻译质量之间失焦。

## 决策

第一版的首要成功标准是：用户阅读外文网页时，可以一键将整页翻译为目标语言，并尽量保持原网页结构与交互。

选中文本翻译属于重要能力，但不取代整页翻译作为产品主场景。

## 影响

- 核心设计围绕内容脚本、DOM 文本节点识别、分段翻译和结果回写展开。
- 翻译质量、页面稳定性和可恢复性优先于供应商数量。
- 选中文本翻译应复用同一翻译服务与配置模型。
