# ADR-0032：整页翻译采用带节点 ID 的批量请求

- 状态：已被 ADR-0036 局部取代
- 日期：2026-07-26

## 背景

按单个文本节点逐一请求会在普通网页产生大量网络往返，导致整页翻译等待时间过长。

## 决策

整页翻译当前将每 1 个可见文本节点作为一个请求，最多同时执行 5 个请求。最初所有批次都要求模型返回由 `{ "id", "translation" }` 组成的 JSON 数组；单节点请求的响应协议现由 ADR-0036 优化为纯文本。

批次可以并行请求以缩短总耗时，但完成结果必须按页面节点顺序缓冲和回写；用户不会先看到后面的段落。

选中文本翻译仍使用单段纯译文请求。批量失败会按批重试最多 3 次；最终失败的节点仍可单独或再次批量重试。

## 后果

- 大幅减少请求数，并为同批文本提供有限的上下文。
- 需要处理模型输出 JSON 不完整或格式错误的失败情形。
- 当前批量大小配置为 1，即每节点一个请求；并发限制由 ADR-0021 规定为 5。仅当未来批量大小大于 1 时继续使用带节点 ID 的 JSON 协议。
