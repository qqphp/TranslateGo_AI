# Store listing material

## Short description

Translate selected text and ordinary web pages using your own OpenAI-compatible API.

## Permission and data disclosure

The extension requests `<all_urls>` solely to inject its page UI and read visible text after an explicit user action on ordinary webpages. Text is sent only to the user-configured API endpoint. API keys remain in local extension storage. No telemetry, analytics, webpage content, or translations are retained by the extension.

## Artwork

The build generates 16, 32, 48 and 128 px PNG extension icons. Before submission, capture Chrome and Edge screenshots showing profile setup, selection translation, page translation progress, preserve-original mode, and restore behavior.
