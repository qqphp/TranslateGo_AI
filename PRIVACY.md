# Privacy policy

AI大模型-沉浸式翻译-免费-极简 reads page text only after you explicitly click the page-translation menu entry or the selected-text translation button. It sends that text directly and only to the OpenAI-compatible API URL in your active profile. The extension has no product backend.

API keys, profiles, and the 30 most recent successful translations entered on the extension's Translate page are stored only in `chrome.storage.local`; they are not synchronized. Translate-page history contains the original text, translated text, selected languages, and creation time. Webpage originals and webpage translations are not persisted. The extension does not store full API request bodies or collect telemetry, analytics, or usage statistics.

`<all_urls>` is required so you can explicitly translate ordinary pages on any site. Browser-restricted pages, including `chrome://`, `edge://`, extension pages, and the Chrome Web Store, are not supported.
