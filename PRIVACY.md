# Privacy policy

LLM Web Translator reads page text only after you explicitly click the page-translation menu entry or the selected-text translation button. It sends that text directly and only to the OpenAI-compatible API URL in your active profile. The extension has no product backend.

API keys and profiles are stored only in `chrome.storage.local`; they are not synchronized. The extension does not persist page originals, translations, or full API request bodies, and it does not collect telemetry, analytics, or usage statistics.

`<all_urls>` is required so you can explicitly translate ordinary pages on any site. Browser-restricted pages, including `chrome://`, `edge://`, extension pages, and the Chrome Web Store, are not supported.
